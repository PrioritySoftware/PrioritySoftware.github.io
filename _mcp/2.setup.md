<a name="Setup"></a>
## Setup & Configuration

<a class="anchor-link" name="Endpoint"></a>
### Endpoint

The Priority MCP Server uses the streamable HTTP transport protocol. Connect your MCP client to:

```
https://d.priority-connect.online/mcp/erp
```

For self-hosted deployments, replace with your server's hostname and port 8001:

```
http://your-server:8001/mcp/erp
```

<a class="anchor-link" name="Authentication"></a>
### Authentication

Authentication is handled via HTTP headers sent with every MCP request.

**Required Headers:**

| Header | Description |
|--------|-------------|
| `prettyname` | Your Priority ERP tenant identifier (the tenant's pretty name) |
| `Authorization` | Credentials in Bearer or Basic format |

**Bearer (JWT) authentication** (recommended for SSO):

```
Authorization: Bearer eyJhbGciOiJSUzI1NiIsInR5cCI6IkpXVCJ9...
```

**Basic authentication:**

```
Authorization: Basic dXNlcm5hbWU6cGFzc3dvcmQ=
```

The Base64 value encodes `username:password`.

<a class="anchor-link" name="Client_Configuration"></a>
### Client Configuration

Below are configuration examples for common MCP clients.

<a class="anchor-link" name="Claude_Code"></a>
### Claude Code

Add to your project's `.mcp.json` or global MCP settings:

```json
{
  "mcpServers": {
    "priority-mcp": {
      "type": "streamableHttp",
      "url": "https://d.priority-connect.online/mcp/erp",
      "headers": {
        "prettyname": "your-tenant-name",
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}
```

<a class="anchor-link" name="Cline"></a>
### Cline

Add to your Cline MCP settings (`~/.cline/mcp_settings.json`):

```json
{
  "mcpServers": {
    "priority-mcp": {
      "autoApprove": [],
      "disabled": false,
      "timeout": 60,
      "type": "streamableHttp",
      "url": "https://d.priority-connect.online/mcp/erp",
      "headers": {
        "prettyname": "your-tenant-name",
        "Authorization": "Bearer YOUR_JWT_TOKEN"
      }
    }
  }
}
```

<a class="anchor-link" name="Other_MCP_Clients"></a>
### Other MCP Clients

Any MCP client that supports streamable HTTP transport can connect. Configure it with:

| Setting | Value |
|---------|-------|
| Transport | Streamable HTTP |
| URL | `https://d.priority-connect.online/mcp/erp` |
| Headers | `prettyname` and `Authorization` (see above) |
| Timeout | 60 seconds recommended |
